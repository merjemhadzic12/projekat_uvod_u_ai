Projekat iz predmeta **Uvod u vjestacku inteligenciju**.

## Opis problema
Cilj projekta je rješavanje problema usmjeravanja heterogene flote vozila sa vremenskim prozorima (*Heterogeneous Fleet Vehicle Routing Problem with Time Windows — HFVRPTW*) na primjeru distribucije robe između centralnog skladišta i maloprodajnih objekata (marketa) u Bosni i Hercegovini.

## Struktura repozitorija
* `README.md` — osnovne informacije o projektu i uputstvo za pokretanje
* `DNEVNIK.md` — hronološki pregled napretka i odluka tokom izrade projekta
* `AI_IZJAVA.md` — evidencija korištenja alata umjetne inteligencije
* `requirements.txt` — lista potrebnih Python biblioteka
